# stripe-bfcm-dashboard

Builds a Black Friday and Cyber Monday (BFCM) season dashboard of payments, customers, and recurring revenue from the connected Stripe MCP account, as a hosted dashboard or artifact where the agent's tools support one, otherwise as one HTML file. For the 2026 BFCM season only. Use when a merchant asks for a BFCM, Black Friday, Cyber Monday, holiday, holiday sales, or peak-season dashboard, such as "build me a holiday dashboard" or "build me a Cyber Monday dashboard," even without the word BFCM.

This plugin packages the [`stripe-bfcm-dashboard`](skills/stripe-bfcm-dashboard/SKILL.md) skill from
[stripe/ai](https://github.com/stripe/ai/tree/main/skills/stripe-bfcm-dashboard) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/stripe-bfcm-dashboard/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install stripe-bfcm-dashboard@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dstripe-bfcm-dashboard),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `stripe-bfcm-dashboard`.
