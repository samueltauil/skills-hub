# landing-page-conversion-audit

Audit a landing page, sales page or checkout page for conversion leaks and return a fix list ordered by expected revenue impact. Use when asked to review, critique or improve a landing page, sales page, opt-in page, product page or checkout flow, when conversion rate is low, when paid traffic is not converting, or when someone asks "why isn't this page converting" or wants a CRO / landing page review.

This plugin packages the [`landing-page-conversion-audit`](skills/landing-page-conversion-audit/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/landing-page-conversion-audit) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/landing-page-conversion-audit/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install landing-page-conversion-audit@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dlanding-page-conversion-audit),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `landing-page-conversion-audit`.
