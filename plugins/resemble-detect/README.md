# resemble-detect

Deepfake detection and media safety — detect AI-generated audio, images, video, and text, trace synthesis sources, apply watermarks, verify speaker identity, and analyze media intelligence using Resemble AI

This plugin packages the [`resemble-detect`](skills/resemble-detect/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/resemble-detect) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/resemble-detect/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install resemble-detect@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dresemble-detect),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `resemble-detect`.
