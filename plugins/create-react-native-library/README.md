# create-react-native-library

Scaffolds React Native libraries with create-react-native-library for standalone libraries or local native modules and views. Use when creating or working on React Native libraries or adding native functionality in an existing app.

This plugin packages the [`create-react-native-library`](skills/create-react-native-library/SKILL.md) skill from
[callstackincubator/agent-skills](https://github.com/callstackincubator/agent-skills/tree/main/skills/create-react-native-library) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-react-native-library/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-react-native-library@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-react-native-library),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-react-native-library`.
