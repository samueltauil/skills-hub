# google-cloud-waf-security

Evaluates Google Cloud workloads and provides actionable recommendations for identity management, access control, permissions and roles, network and perimeter security, data security and encryption, security logging and threat detection, software supply chain hardening, AI security, data privacy, regulatory compliance, and cloud sovereignty. The recommendations are aligned with the Security, Privacy, and Compliance pillar of the Google Cloud Well-Architected Framework (WAF). Use when the user asks about firewall rules, zero trust, shared responsibility and shared fate, audit logging, security monitoring, threat mitigation, shift-left CI/CD security, Secure AI Framework (SAIF), data residency, or hardening Google Cloud resources. Don't use for other Well-Architected Framework pillars (Cost Optimization, Operational Excellence, Reliability, Performance Optimization, or Sustainability).

This plugin packages the [`google-cloud-waf-security`](skills/google-cloud-waf-security/SKILL.md) skill from
