# create-technical-spike

Create time-boxed technical spike documents for researching and resolving critical development decisions before implementation.

This plugin packages the [`create-technical-spike`](skills/create-technical-spike/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-technical-spike) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-technical-spike/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-technical-spike@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-technical-spike),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-technical-spike`.
