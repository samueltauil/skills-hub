# react18-dep-compatibility

React 18.3.1 and React 19 dependency compatibility matrix.

This plugin packages the [`react18-dep-compatibility`](skills/react18-dep-compatibility/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/react18-dep-compatibility) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/react18-dep-compatibility/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install react18-dep-compatibility@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dreact18-dep-compatibility),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `react18-dep-compatibility`.
