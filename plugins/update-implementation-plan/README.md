# update-implementation-plan

Update an existing implementation plan file with new or update requirements to provide new features, refactoring existing code or upgrading packages, design, architecture or infrastructure.

This plugin packages the [`update-implementation-plan`](skills/update-implementation-plan/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/update-implementation-plan) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/update-implementation-plan/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install update-implementation-plan@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dupdate-implementation-plan),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `update-implementation-plan`.
