# create-quarkus-project

Create a new Quarkus project (Maven or Gradle) with the Quarkus CLI, code.quarkus.io API or Maven plugin, choose extensions, and run it in dev mode. Use when asked to scaffold, bootstrap or start a Quarkus application or REST API.

This plugin packages the [`create-quarkus-project`](skills/create-quarkus-project/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-quarkus-project) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-quarkus-project/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-quarkus-project@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-quarkus-project),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-quarkus-project`.
