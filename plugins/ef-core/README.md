# ef-core

Get best practices for Entity Framework Core

This plugin packages the [`ef-core`](skills/ef-core/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/ef-core) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/ef-core/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install ef-core@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Def-core),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `ef-core`.
