# ui-screenshots

Capture screenshots of web apps during development using Playwright and PIL. Supports full-page captures, interactive states, and an iterate-on-crop workflow that avoids slow re-screenshots.

This plugin packages the [`ui-screenshots`](skills/ui-screenshots/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/ui-screenshots) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/ui-screenshots/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install ui-screenshots@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dui-screenshots),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `ui-screenshots`.
