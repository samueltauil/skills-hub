# github-actions-efficiency

Audit GitHub Actions workflow efficiency and recommend fixes to reduce CI minutes and costs.

This plugin packages the [`github-actions-efficiency`](skills/github-actions-efficiency/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/github-actions-efficiency) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/github-actions-efficiency/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install github-actions-efficiency@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgithub-actions-efficiency),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `github-actions-efficiency`.
