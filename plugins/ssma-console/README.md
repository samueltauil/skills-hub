## Install

```sh

copilot plugin install ssma-console@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dssma-console),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `ssma-console`.
