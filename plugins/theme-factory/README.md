# theme-factory

Toolkit for styling artifacts with a theme. These artifacts can be slides, docs, reportings, HTML landing pages, etc. There are 10 pre-set themes with colors/fonts that you can apply to any artifact that has been creating, or can generate a new theme on-the-fly.

This plugin packages the [`theme-factory`](skills/theme-factory/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/theme-factory) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/theme-factory/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install theme-factory@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dtheme-factory),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `theme-factory`.
