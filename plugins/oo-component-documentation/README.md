# oo-component-documentation

Create or update standardized object-oriented component documentation using a shared template plus mode-specific guidance for new and existing docs.

This plugin packages the [`oo-component-documentation`](skills/oo-component-documentation/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/oo-component-documentation) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/oo-component-documentation/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install oo-component-documentation@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Doo-component-documentation),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `oo-component-documentation`.
