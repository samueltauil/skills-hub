# competitor-ad-intelligence

Use this skill when the user asks to analyze, tear down, or reverse-engineer a competitor's paid ads. Trigger for prompts like "what ads is [competitor] running", "tear down their ad strategy", "competitor ad analysis", "find ad angles we haven't tried", or "reverse-engineer their paid funnel". Do not trigger for organic/SEO competitor research or website positioning analysis.

This plugin packages the [`competitor-ad-intelligence`](skills/competitor-ad-intelligence/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/competitor-ad-intelligence) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/competitor-ad-intelligence/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install competitor-ad-intelligence@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcompetitor-ad-intelligence),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `competitor-ad-intelligence`.
