# algorithmic-art

Creating algorithmic art using p5.js with seeded randomness and interactive parameter exploration. Use this when users request creating art using code, generative art, algorithmic art, flow fields, or particle systems. Create original algorithmic art rather than copying existing artists' work to avoid copyright violations.

This plugin packages the [`algorithmic-art`](skills/algorithmic-art/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/algorithmic-art) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/algorithmic-art/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install algorithmic-art@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dalgorithmic-art),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `algorithmic-art`.
