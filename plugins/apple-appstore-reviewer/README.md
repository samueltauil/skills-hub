# apple-appstore-reviewer

Serves as a reviewer of the codebase with instructions on looking for Apple App Store optimizations or rejection reasons.

This plugin packages the [`apple-appstore-reviewer`](skills/apple-appstore-reviewer/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/apple-appstore-reviewer) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/apple-appstore-reviewer/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install apple-appstore-reviewer@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dapple-appstore-reviewer),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `apple-appstore-reviewer`.
