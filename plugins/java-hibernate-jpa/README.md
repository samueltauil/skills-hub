# java-hibernate-jpa

Diagnose and fix Hibernate ORM / Jakarta Persistence problems in plain Java: N+1 queries, lazy loading errors, identifier generation, entity equals/hashCode, cascades, pagination, batching, locking, caching, Lombok on entities, and Hibernate 6/7 differences. Use when reviewing or writing JPA entities, mappings, and queries. Framework-neutral.

This plugin packages the [`java-hibernate-jpa`](skills/java-hibernate-jpa/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/java-hibernate-jpa) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/java-hibernate-jpa/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.
