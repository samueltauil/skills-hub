# writing-guidelines

Review docs/prose for Writing Guidelines compliance. Use when asked to "review my docs", "check writing style", "audit prose", "review docs voice and tone", or "check this page against the writing handbook".

This plugin packages the [`writing-guidelines`](skills/writing-guidelines/SKILL.md) skill from
[vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/writing-guidelines) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/writing-guidelines/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install writing-guidelines@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dwriting-guidelines),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `writing-guidelines`.
