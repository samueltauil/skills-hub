# google-cloud-recipe-auth

Provides expert guidance on Identity and Access Management (IAM) and authenticating and authorizing to Google Cloud services and APIs, covering human users, service identities, Application Default Credentials (ADC), and best practices for secure access.

This plugin packages the [`google-cloud-recipe-auth`](skills/google-cloud-recipe-auth/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/google-cloud-recipe-auth) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-cloud-recipe-auth/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install google-cloud-recipe-auth@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgoogle-cloud-recipe-auth),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `google-cloud-recipe-auth`.
