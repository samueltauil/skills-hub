# canvas-design

Create beautiful visual art in .png and .pdf documents using design philosophy. You should use this skill when the user asks to create a poster, piece of art, design, or other static piece. Create original visual designs, never copying existing artists' work to avoid copyright violations.

This plugin packages the [`canvas-design`](skills/canvas-design/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/canvas-design) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/canvas-design/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install canvas-design@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcanvas-design),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `canvas-design`.
