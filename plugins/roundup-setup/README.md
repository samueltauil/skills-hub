# roundup-setup

Interactive onboarding that learns your communication style, audiences, and data sources to configure personalized status briefings. Paste in examples of updates you already write, answer a few questions, and roundup calibrates itself to your workflow.

This plugin packages the [`roundup-setup`](skills/roundup-setup/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/roundup-setup) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/roundup-setup/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install roundup-setup@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Droundup-setup),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `roundup-setup`.
