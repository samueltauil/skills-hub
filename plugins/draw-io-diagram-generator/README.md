# draw-io-diagram-generator

Use when creating, editing, or generating draw.io diagram files (.drawio, .drawio.svg, .drawio.png). Covers mxGraph XML authoring, shape libraries, style strings, flowcharts, system architecture, sequence diagrams, ER diagrams, UML class diagrams, network topology, layout strategy, the hediet.vscode-drawio VS Code extension, and the full agent workflow from request to a ready-to-open file.

This plugin packages the [`draw-io-diagram-generator`](skills/draw-io-diagram-generator/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/draw-io-diagram-generator) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/draw-io-diagram-generator/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install draw-io-diagram-generator@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddraw-io-diagram-generator),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `draw-io-diagram-generator`.
