# gtm-enterprise-onboarding

Four-phase framework for onboarding enterprise customers from contract to value realization. Use when implementing new enterprise customers, preventing churn during onboarding, or solving the adoption cliff that kills deals post-go-live. Includes the Week 4 ghosting pattern.

This plugin packages the [`gtm-enterprise-onboarding`](skills/gtm-enterprise-onboarding/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-enterprise-onboarding) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-enterprise-onboarding/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-enterprise-onboarding@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-enterprise-onboarding),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-enterprise-onboarding`.
