# aws-cdk-python-setup

Setup and initialization guide for developing AWS CDK (Cloud Development Kit) applications in Python. This skill enables users to configure environment prerequisites, create new CDK projects, manage dependencies, and deploy to AWS.

This plugin packages the [`aws-cdk-python-setup`](skills/aws-cdk-python-setup/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/aws-cdk-python-setup) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/aws-cdk-python-setup/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install aws-cdk-python-setup@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Daws-cdk-python-setup),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `aws-cdk-python-setup`.
