# openapi-to-application-code

Generate a complete, production-ready application from an OpenAPI specification

This plugin packages the [`openapi-to-application-code`](skills/openapi-to-application-code/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/openapi-to-application-code) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/openapi-to-application-code/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install openapi-to-application-code@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dopenapi-to-application-code),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `openapi-to-application-code`.
