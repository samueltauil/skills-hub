# power-platform-mcp-connector-suite

Generate complete Power Platform custom connector with MCP integration for Copilot Studio - includes schema generation, troubleshooting, and validation

This plugin packages the [`power-platform-mcp-connector-suite`](skills/power-platform-mcp-connector-suite/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/power-platform-mcp-connector-suite) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/power-platform-mcp-connector-suite/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install power-platform-mcp-connector-suite@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpower-platform-mcp-connector-suite),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `power-platform-mcp-connector-suite`.
