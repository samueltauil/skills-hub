# web-design-guidelines

Review UI code for Web Interface Guidelines compliance. Use when asked to "review my UI", "check accessibility", "audit design", "review UX", or "check my site against best practices".

This plugin packages the [`web-design-guidelines`](skills/web-design-guidelines/SKILL.md) skill from
[vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/web-design-guidelines/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install web-design-guidelines@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dweb-design-guidelines),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `web-design-guidelines`.
