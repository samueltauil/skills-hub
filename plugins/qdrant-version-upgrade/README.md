# qdrant-version-upgrade

Guidance on how to upgrade your Qdrant version without interrupting the availability of your application and ensuring data integrity.

This plugin packages the [`qdrant-version-upgrade`](skills/qdrant-version-upgrade/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/qdrant-version-upgrade) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/qdrant-version-upgrade/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install qdrant-version-upgrade@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dqdrant-version-upgrade),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `qdrant-version-upgrade`.
