# update-specification

Update an existing specification file for the solution, optimized for Generative AI consumption based on new requirements or updates to any existing code.

This plugin packages the [`update-specification`](skills/update-specification/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/update-specification) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/update-specification/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install update-specification@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dupdate-specification),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `update-specification`.
