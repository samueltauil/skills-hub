# finalize-agent-prompt

Finalize prompt file using the role of an AI agent to polish the prompt for the end user.

This plugin packages the [`finalize-agent-prompt`](skills/finalize-agent-prompt/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/finalize-agent-prompt) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/finalize-agent-prompt/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install finalize-agent-prompt@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfinalize-agent-prompt),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `finalize-agent-prompt`.
