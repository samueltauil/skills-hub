# gen-specs-as-issues

This workflow guides you through a systematic approach to identify missing features, prioritize them, and create detailed specifications for implementation.

This plugin packages the [`gen-specs-as-issues`](skills/gen-specs-as-issues/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gen-specs-as-issues) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gen-specs-as-issues/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gen-specs-as-issues@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgen-specs-as-issues),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gen-specs-as-issues`.
