# notion-research-documentation

Research across Notion and synthesize into structured documentation; use when gathering info from multiple Notion sources to produce briefs, comparisons, or reports with citations.

This plugin packages the [`notion-research-documentation`](skills/notion-research-documentation/SKILL.md) skill from
[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated/notion-research-documentation) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/notion-research-documentation/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh

copilot plugin install notion-research-documentation@skills-hub
```

search for `notion-research-documentation`.
