# breakdown-epic-arch

Prompt for creating the high-level technical architecture for an Epic, based on a Product Requirements Document.

This plugin packages the [`breakdown-epic-arch`](skills/breakdown-epic-arch/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/breakdown-epic-arch) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/breakdown-epic-arch/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install breakdown-epic-arch@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbreakdown-epic-arch),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `breakdown-epic-arch`.
