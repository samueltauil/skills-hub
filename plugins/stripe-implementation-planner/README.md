# stripe-implementation-planner

Plans Stripe product selection and integration architecture for an initial Stripe setup or a material expansion of an existing setup. Use when the user needs personalized recommendations based on their business model, payment models, sales channels, geography, or platform requirements, including requests to plan and build an integration. Don't use for API-version upgrades, product-availability questions, existing-integration debugging, webhook troubleshooting, narrow code changes, product explanations, PR review alone, unrelated implementation planning, or when the user explicitly asks to skip planning.

This plugin packages the [`stripe-implementation-planner`](skills/stripe-implementation-planner/SKILL.md) skill from
[stripe/ai](https://github.com/stripe/ai/tree/main/skills/stripe-implementation-planner) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/stripe-implementation-planner/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.
