# gtm-technical-product-pricing

Pricing strategy for technical products. Use when choosing usage-based vs seat-based, designing freemium thresholds, structuring enterprise pricing conversations, deciding when to raise prices, or using price as a positioning signal.

This plugin packages the [`gtm-technical-product-pricing`](skills/gtm-technical-product-pricing/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-technical-product-pricing) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-technical-product-pricing/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-technical-product-pricing@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-technical-product-pricing),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-technical-product-pricing`.
