# sentry-brand-guidelines

Write copy following Sentry brand guidelines. Use when writing UI text, error messages, empty states, onboarding flows, 404 pages, documentation, marketing copy, or any user-facing content. Covers both Plain Speech (default) and Sentry Voice tones.

This plugin packages the [`brand-guidelines`](skills/brand-guidelines/SKILL.md) skill from
[getsentry/skills](https://github.com/getsentry/skills/tree/main/skills/brand-guidelines) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/sentry-brand-guidelines/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install sentry-brand-guidelines@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dsentry-brand-guidelines),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `sentry-brand-guidelines`.
