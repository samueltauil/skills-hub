# markdown-to-word-mermaid

Export Markdown containing Mermaid code fences to Word (.docx) with embedded SVG diagrams and PNG fallbacks. Use when diagram sharpness, Office-compatible labels, or page-aware placement matters. Not for Word-to-Markdown conversion, editable Office shapes, or general slide creation.

This plugin packages the [`markdown-to-word-mermaid`](skills/markdown-to-word-mermaid/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/markdown-to-word-mermaid) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/markdown-to-word-mermaid/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install markdown-to-word-mermaid@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dmarkdown-to-word-mermaid),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `markdown-to-word-mermaid`.
