# microsoft-store-publisher

Prepare, validate, submit, and monitor Windows desktop apps in Microsoft Partner Center. Use for MSIX packaging, Store identity, listings, WACK, Partner Center automation, certification, and publishing.

This plugin packages the [`microsoft-store-publisher`](skills/microsoft-store-publisher/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/microsoft-store-publisher) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/microsoft-store-publisher/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install microsoft-store-publisher@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dmicrosoft-store-publisher),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `microsoft-store-publisher`.
