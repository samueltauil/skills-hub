# power-bi-dax-optimization

Comprehensive Power BI DAX formula optimization prompt for improving performance, readability, and maintainability of DAX calculations.

This plugin packages the [`power-bi-dax-optimization`](skills/power-bi-dax-optimization/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/power-bi-dax-optimization) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/power-bi-dax-optimization/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install power-bi-dax-optimization@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpower-bi-dax-optimization),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `power-bi-dax-optimization`.
