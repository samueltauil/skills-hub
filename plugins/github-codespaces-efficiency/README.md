# github-codespaces-efficiency

Audit and improve GitHub Codespaces efficiency. Use this skill when a user wants faster Codespaces startup, lower Codespaces spend, slim devcontainers, right-size machines, tune idle timeout, or scope prebuilds to branches with sustained usage.

This plugin packages the [`github-codespaces-efficiency`](skills/github-codespaces-efficiency/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/github-codespaces-efficiency) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/github-codespaces-efficiency/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install github-codespaces-efficiency@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgithub-codespaces-efficiency),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `github-codespaces-efficiency`.
