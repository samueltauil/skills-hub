# ima-sdk-client-side

Supports Interactive Media Ads (IMA) SDK. Use this skill for client-side ad insertion when you are requesting video ads for websites, apps, TVs or other platforms using VAST or VMAP. Do not use for Dynamic Ad Insertion (DAI), SSAI, or SGAI.

This plugin packages the [`ima-sdk-client-side`](skills/ima-sdk-client-side/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/ads/ima-sdk-client-side) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/ima-sdk-client-side/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install ima-sdk-client-side@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dima-sdk-client-side),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `ima-sdk-client-side`.
