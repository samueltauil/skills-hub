# cloudflare-one-migrations

Assess and plan migrations from existing VPN, SWG, or SASE platforms to Cloudflare One, including policy mapping, parity gaps, and rollout.

This plugin packages the [`cloudflare-one-migrations`](skills/cloudflare-one-migrations/SKILL.md) skill from
[cloudflare/skills](https://github.com/cloudflare/skills/tree/main/skills/cloudflare-one-migrations) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/cloudflare-one-migrations/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install cloudflare-one-migrations@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcloudflare-one-migrations),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `cloudflare-one-migrations`.
