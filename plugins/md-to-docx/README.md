# md-to-docx

Convert Markdown files to professionally formatted Word (.docx) documents with embedded PNG images — pure JavaScript, no external tools required

This plugin packages the [`md-to-docx`](skills/md-to-docx/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/md-to-docx) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/md-to-docx/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install md-to-docx@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dmd-to-docx),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `md-to-docx`.
