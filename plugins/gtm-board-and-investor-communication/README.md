# gtm-board-and-investor-communication

Board meeting preparation, investor updates, and executive communication. Use when preparing board decks, writing investor updates, handling bad news with the board, structuring QBRs, or building board-level metric discipline. Includes the "Three Things" narrative model, the 4-tier metric hierarchy, and the pre-brief pattern that prevents board surprises.

This plugin packages the [`gtm-board-and-investor-communication`](skills/gtm-board-and-investor-communication/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-board-and-investor-communication) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-board-and-investor-communication/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install
