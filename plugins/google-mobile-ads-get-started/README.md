# google-mobile-ads-get-started

Provides instructions for integrating the Google Mobile Ads (GMA) SDK. Use this skill when the user wants to get started with, install, integrate, set up, or configure the SDK for AdMob or Ad Manager, GMA Next-Gen SDK or mobile ads framework in an Android, iOS, or Unity application.

This plugin packages the [`google-mobile-ads-get-started`](skills/google-mobile-ads-get-started/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/ads/google-mobile-ads-get-started) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-mobile-ads-get-started/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install google-mobile-ads-get-started@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgoogle-mobile-ads-get-started),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `google-mobile-ads-get-started`.
