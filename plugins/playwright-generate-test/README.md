# playwright-generate-test

Generate a Playwright test based on a scenario using Playwright MCP

This plugin packages the [`playwright-generate-test`](skills/playwright-generate-test/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/playwright-generate-test) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/playwright-generate-test/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install playwright-generate-test@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dplaywright-generate-test),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `playwright-generate-test`.
