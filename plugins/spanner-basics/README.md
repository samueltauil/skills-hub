# spanner-basics

Assists in provisioning instances and databases, designing performant schemas, and querying data in Cloud Spanner on Google Cloud. Use when designing primary keys, writing SQL queries or client library code, or diagnosing performance issues.

This plugin packages the [`spanner-basics`](skills/spanner-basics/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/spanner-basics) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/spanner-basics/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install spanner-basics@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dspanner-basics),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `spanner-basics`.
