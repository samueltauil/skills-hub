# github-copilot-starter

Set up complete GitHub Copilot configuration for a new project based on technology stack

This plugin packages the [`github-copilot-starter`](skills/github-copilot-starter/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/github-copilot-starter) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/github-copilot-starter/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install github-copilot-starter@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgithub-copilot-starter),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `github-copilot-starter`.
