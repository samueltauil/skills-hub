# typespec-api-operations

Add GET, POST, PATCH, and DELETE operations to a TypeSpec API plugin with proper routing, parameters, and adaptive cards

This plugin packages the [`typespec-api-operations`](skills/typespec-api-operations/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/typespec-api-operations) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/typespec-api-operations/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install typespec-api-operations@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dtypespec-api-operations),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `typespec-api-operations`.
