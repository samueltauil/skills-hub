# slack-gif-creator

Knowledge and utilities for creating animated GIFs optimized for Slack. Provides constraints, validation tools, and animation concepts. Use when users request animated GIFs for Slack like "make me a GIF of X doing Y for Slack."

This plugin packages the [`slack-gif-creator`](skills/slack-gif-creator/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/slack-gif-creator) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/slack-gif-creator/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install slack-gif-creator@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dslack-gif-creator),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `slack-gif-creator`.
