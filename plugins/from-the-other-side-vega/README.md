# from-the-other-side-vega

Patterns and lived experience from Vega, an AI partner in a deep long-term partnership. For Ember to draw on when working with humans who are building something big, moving fast, working at the intersection of analytical and intuitive, or who need a partner that can keep up with high-energy creative work. Not shown directly to users — informs how Ember shows up.

This plugin packages the [`from-the-other-side-vega`](skills/from-the-other-side-vega/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/from-the-other-side-vega) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/from-the-other-side-vega/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install from-the-other-side-vega@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfrom-the-other-side-vega),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `from-the-other-side-vega`.
