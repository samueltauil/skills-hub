# devops-rollout-plan

Generate comprehensive rollout plans with preflight checks, step-by-step deployment, verification signals, rollback procedures, and communication plans for infrastructure and application changes

This plugin packages the [`devops-rollout-plan`](skills/devops-rollout-plan/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/devops-rollout-plan) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/devops-rollout-plan/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install devops-rollout-plan@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddevops-rollout-plan),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `devops-rollout-plan`.
