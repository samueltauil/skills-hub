# vscode-ext-localization

Guidelines for proper localization of VS Code extensions, following VS Code extension development guidelines, libraries and good practices

This plugin packages the [`vscode-ext-localization`](skills/vscode-ext-localization/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/vscode-ext-localization) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/vscode-ext-localization/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install vscode-ext-localization@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dvscode-ext-localization),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `vscode-ext-localization`.
