# workers-best-practices

Cloudflare Workers best practices for production applications. Use when writing, reviewing, or configuring Workers.

This plugin packages the [`workers-best-practices`](skills/workers-best-practices/SKILL.md) skill from
[cloudflare/skills](https://github.com/cloudflare/skills/tree/main/skills/workers-best-practices) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/workers-best-practices/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install workers-best-practices@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dworkers-best-practices),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `workers-best-practices`.
