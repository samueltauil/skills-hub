# define-goal

Help the user define a concrete, measurable goal before starting work, especially when they ask to use the goal tool, create a goal, set an objective, clarify success criteria, or turn a fuzzy intention into a quantitative outcome. Use this skill for goal creation and goal refinement only; it does not manage durable snapshots, decision logs, or long-running execution artifacts.

This plugin packages the [`define-goal`](skills/define-goal/SKILL.md) skill from
[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated/define-goal) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/define-goal/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install define-goal@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddefine-goal),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `define-goal`.
