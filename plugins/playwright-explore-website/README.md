# playwright-explore-website

Website exploration for testing using Playwright MCP

This plugin packages the [`playwright-explore-website`](skills/playwright-explore-website/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/playwright-explore-website) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/playwright-explore-website/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install playwright-explore-website@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dplaywright-explore-website),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `playwright-explore-website`.
