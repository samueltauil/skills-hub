# sred-project-organizer

Take a list of projects and their related documentation, and organize them into the SRED format for submission.

This plugin packages the [`sred-project-organizer`](skills/sred-project-organizer/SKILL.md) skill from
[getsentry/skills](https://github.com/getsentry/skills/tree/main/skills/sred-project-organizer) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/sred-project-organizer/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install sred-project-organizer@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dsred-project-organizer),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `sred-project-organizer`.
