This plugin packages the [`playwright-automation-fill-in-form`](skills/playwright-automation-fill-in-form/SKILL.md) skill from

## Install

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install playwright-automation-fill-in-form@skills-hub
```

search for `playwright-automation-fill-in-form`.
