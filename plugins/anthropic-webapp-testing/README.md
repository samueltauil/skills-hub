# anthropic-webapp-testing

Toolkit for interacting with and testing local web applications using Playwright. Supports verifying frontend functionality, debugging UI behavior, capturing browser screenshots, and viewing browser logs.

This plugin packages the [`webapp-testing`](skills/webapp-testing/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/webapp-testing) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/anthropic-webapp-testing/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install anthropic-webapp-testing@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Danthropic-webapp-testing),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `anthropic-webapp-testing`.
