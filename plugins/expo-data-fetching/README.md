# expo-data-fetching

Implement or debug data fetching in Expo apps. Use for fetch API calls, React Query, SWR, authenticated requests, caching, retries, offline support, loading and error states, or Expo Router data loaders (useLoaderData).

This plugin packages the [`expo-data-fetching`](skills/expo-data-fetching/SKILL.md) skill from
[expo/skills](https://github.com/expo/skills/tree/main/plugins/expo/skills/expo-data-fetching) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/expo-data-fetching/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install expo-data-fetching@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dexpo-data-fetching),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `expo-data-fetching`.
