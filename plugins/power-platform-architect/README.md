# power-platform-architect

Use this skill when the user needs to transform business requirements, use case descriptions, or meeting transcripts into a technical Power Platform solution architecture, including component selection and Mermaid.js diagrams.

This plugin packages the [`power-platform-architect`](skills/power-platform-architect/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/power-platform-architect) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/power-platform-architect/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install power-platform-architect@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpower-platform-architect),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `power-platform-architect`.
