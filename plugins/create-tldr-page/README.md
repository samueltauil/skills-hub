# create-tldr-page

Create a tldr page from documentation URLs and command examples, requiring both URL and command name.

This plugin packages the [`create-tldr-page`](skills/create-tldr-page/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-tldr-page) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-tldr-page/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-tldr-page@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-tldr-page),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-tldr-page`.
