# bug-reproduction-brief

Turn a vague, intermittent, or environment-specific bug report into a minimal evidence-backed reproduction before proposing a fix.

This plugin packages the [`bug-reproduction-brief`](skills/bug-reproduction-brief/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/bug-reproduction-brief) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/bug-reproduction-brief/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install bug-reproduction-brief@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbug-reproduction-brief),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `bug-reproduction-brief`.
