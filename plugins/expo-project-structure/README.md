# expo-project-structure

Folder structure for a new Expo app. Use when scaffolding or laying out a new Expo project with Expo Router, or deciding where a file should live in one. For new projects only — never restructure an existing app to match.

This plugin packages the [`expo-project-structure`](skills/expo-project-structure/SKILL.md) skill from
[expo/skills](https://github.com/expo/skills/tree/main/plugins/expo/skills/expo-project-structure) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/expo-project-structure/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install expo-project-structure@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dexpo-project-structure),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `expo-project-structure`.
