# breakdown-feature-prd

Prompt for creating Product Requirements Documents (PRDs) for new features, based on an Epic.

This plugin packages the [`breakdown-feature-prd`](skills/breakdown-feature-prd/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/breakdown-feature-prd) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/breakdown-feature-prd/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install breakdown-feature-prd@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbreakdown-feature-prd),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `breakdown-feature-prd`.
