# dotnet-upgrade

Ready-to-use prompts for comprehensive .NET framework upgrade analysis and execution

This plugin packages the [`dotnet-upgrade`](skills/dotnet-upgrade/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/dotnet-upgrade) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/dotnet-upgrade/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install dotnet-upgrade@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddotnet-upgrade),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `dotnet-upgrade`.
