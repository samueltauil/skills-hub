# write-coding-standards-from-file

Write a coding standards document for a project using the coding styles from the file(s) and/or folder(s) passed as arguments in the prompt.

This plugin packages the [`write-coding-standards-from-file`](skills/write-coding-standards-from-file/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/write-coding-standards-from-file) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/write-coding-standards-from-file/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install write-coding-standards-from-file@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dwrite-coding-standards-from-file),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `write-coding-standards-from-file`.
