# react19-test-patterns

Provides before/after patterns for migrating test files to React 19 compatibility, including act() imports, Simulate removal, and StrictMode call count changes.

This plugin packages the [`react19-test-patterns`](skills/react19-test-patterns/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/react19-test-patterns) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/react19-test-patterns/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install react19-test-patterns@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dreact19-test-patterns),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `react19-test-patterns`.
