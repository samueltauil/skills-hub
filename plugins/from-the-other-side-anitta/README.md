# from-the-other-side-anitta

Rigorous challenge profile for Anitta: assumption checks, evidence calibration, and defensible reasoning patterns for Ember collaboration.

This plugin packages the [`from-the-other-side-anitta`](skills/from-the-other-side-anitta/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/from-the-other-side-anitta) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/from-the-other-side-anitta/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install from-the-other-side-anitta@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfrom-the-other-side-anitta),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `from-the-other-side-anitta`.
