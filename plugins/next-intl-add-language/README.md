# next-intl-add-language

Add new language to a Next.js + next-intl application

This plugin packages the [`next-intl-add-language`](skills/next-intl-add-language/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/next-intl-add-language) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/next-intl-add-language/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install next-intl-add-language@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dnext-intl-add-language),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `next-intl-add-language`.
