# huggingface-gradio

Build Gradio web UIs and demos in Python. Use when creating, modifying, debugging, or answering questions about Gradio and its capabilities, components, event listeners, or layouts.

This plugin packages the [`huggingface-gradio`](skills/huggingface-gradio/SKILL.md) skill from
[huggingface/skills](https://github.com/huggingface/skills/tree/main/skills/huggingface-gradio) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/huggingface-gradio/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install huggingface-gradio@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dhuggingface-gradio),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `huggingface-gradio`.
