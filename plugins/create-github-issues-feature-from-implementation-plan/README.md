# create-github-issues-feature-from-implementation-plan

Create GitHub Issues from implementation plan phases using feature_request.yml or chore_request.yml templates.

This plugin packages the [`create-github-issues-feature-from-implementation-plan`](skills/create-github-issues-feature-from-implementation-plan/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-github-issues-feature-from-implementation-plan) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-github-issues-feature-from-implementation-plan/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-github-issues-feature-from-implementation-plan@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-github-issues-feature-from-implementation-plan),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-github-issues-feature-from-implementation-plan`.
