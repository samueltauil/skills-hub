# csharp-xunit

Get best practices for XUnit unit testing, including data-driven tests

This plugin packages the [`csharp-xunit`](skills/csharp-xunit/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/csharp-xunit) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/csharp-xunit/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install csharp-xunit@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcsharp-xunit),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `csharp-xunit`.
