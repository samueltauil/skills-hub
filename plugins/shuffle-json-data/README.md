# shuffle-json-data

Shuffle repetitive JSON objects safely by validating schema consistency before randomising entries.

This plugin packages the [`shuffle-json-data`](skills/shuffle-json-data/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/shuffle-json-data) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/shuffle-json-data/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install shuffle-json-data@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dshuffle-json-data),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `shuffle-json-data`.
