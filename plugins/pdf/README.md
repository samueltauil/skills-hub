# pdf

Use this skill whenever the user wants to do anything with PDF files. This includes reading or extracting text/tables from PDFs, combining or merging multiple PDFs into one, splitting PDFs apart, rotating pages, adding watermarks, creating new PDFs, filling PDF forms, encrypting/decrypting PDFs, extracting images, and OCR on scanned PDFs to make them searchable. If the user mentions a .pdf file or asks to produce one, use this skill.

This plugin packages the [`pdf`](skills/pdf/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/pdf) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/pdf/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install pdf@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpdf),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `pdf`.
