# gtm-partnership-architecture

Build and scale partner ecosystems that drive revenue and platform adoption. Use when building partner programs from scratch, tiering partnerships, managing co-marketing, making build-vs-partner decisions, or structuring crawl-walk-run partner deployment.

This plugin packages the [`gtm-partnership-architecture`](skills/gtm-partnership-architecture/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-partnership-architecture) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-partnership-architecture/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-partnership-architecture@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-partnership-architecture),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-partnership-architecture`.
