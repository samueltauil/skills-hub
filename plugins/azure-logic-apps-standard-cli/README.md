# azure-logic-apps-standard-cli

Create, inspect, validate, test, run, debug, package, and deploy Azure Logic Apps Standard projects using the Azure CLI logicapp extension. Use for Standard workflow authoring, optional workspaces, connector discovery, identity-based connections, local runtimes, native workflow tests, and approved cloud lifecycle operations. Not for Consumption-only workflow development.

This plugin packages the [`azure-logic-apps-standard-cli`](skills/azure-logic-apps-standard-cli/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/azure-logic-apps-standard-cli) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/azure-logic-apps-standard-cli/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.
