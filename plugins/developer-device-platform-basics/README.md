# developer-device-platform-basics

Provides guidance and instructions on managing remote devices on Developer Device Platform (DDP). Use when reserving remote Android devices, establishing connection tunnels, checking session status, or extending/cancelling leases. Don't use for iOS or local device/hardware inquiries.

This plugin packages the [`developer-device-platform-basics`](skills/developer-device-platform-basics/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/developer-device-platform-basics) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/developer-device-platform-basics/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install developer-device-platform-basics@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddeveloper-device-platform-basics),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `developer-device-platform-basics`.
