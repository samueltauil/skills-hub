# arch-linux-triage

Triage and resolve Arch Linux issues with pacman, systemd, and rolling-release best practices.

This plugin packages the [`arch-linux-triage`](skills/arch-linux-triage/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/arch-linux-triage) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/arch-linux-triage/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install arch-linux-triage@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Darch-linux-triage),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `arch-linux-triage`.
