# ai-prompt-engineering-safety-review

Comprehensive AI prompt engineering safety review and improvement prompt. Analyzes prompts for safety, bias, security vulnerabilities, and effectiveness while providing detailed improvement recommendations with extensive frameworks, testing methodologies, and educational content.

This plugin packages the [`ai-prompt-engineering-safety-review`](skills/ai-prompt-engineering-safety-review/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/ai-prompt-engineering-safety-review) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/ai-prompt-engineering-safety-review/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install ai-prompt-engineering-safety-review@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dai-prompt-engineering-safety-review),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `ai-prompt-engineering-safety-review`.
