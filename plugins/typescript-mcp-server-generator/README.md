# typescript-mcp-server-generator

Generate a complete MCP server project in TypeScript using the MCP TypeScript SDK v2 (@modelcontextprotocol/server) with tools, resources, and proper configuration

This plugin packages the [`typescript-mcp-server-generator`](skills/typescript-mcp-server-generator/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/typescript-mcp-server-generator) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/typescript-mcp-server-generator/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install typescript-mcp-server-generator@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dtypescript-mcp-server-generator),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `typescript-mcp-server-generator`.
