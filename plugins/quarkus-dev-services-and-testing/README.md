# quarkus-dev-services-and-testing

Quarkus Dev Services and testing: zero-config containers, @QuarkusTest, @QuarkusIntegrationTest, test resources, RestAssured, @InjectMock, profiles and continuous testing. Use when writing or fixing tests in a Quarkus project.

This plugin packages the [`quarkus-dev-services-and-testing`](skills/quarkus-dev-services-and-testing/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/quarkus-dev-services-and-testing) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/quarkus-dev-services-and-testing/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.
