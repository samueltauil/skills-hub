# java-testcontainers

Write reliable integration tests in plain Java with Testcontainers 2.x: JUnit Jupiter lifecycle, singleton containers, reuse, generic containers, wait strategies, networks, init scripts, Docker Compose, CI and Docker/Podman setup. Use when adding or fixing Testcontainers tests, or migrating from 1.x. Framework-neutral.

This plugin packages the [`java-testcontainers`](skills/java-testcontainers/SKILL.md) skill from

by [Skills Hub](https://skillshub.space/skills/java-testcontainers/) and follows the
