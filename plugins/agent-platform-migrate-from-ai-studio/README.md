# agent-platform-migrate-from-ai-studio

Guides agents and users through migrating from Gemini API in Google AI Studio to Gemini Enterprise Agent Platform (formerly Vertex AI). Use this skill when moving applications to Google Cloud, to leverage Cloud credits, or to unify inferencing with other Cloud infrastructure (IAM, billing, telemetry).

This plugin packages the [`agent-platform-migrate-from-ai-studio`](skills/agent-platform-migrate-from-ai-studio/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/agent-platform-migrate-from-ai-studio) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/agent-platform-migrate-from-ai-studio/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install agent-platform-migrate-from-ai-studio@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dagent-platform-migrate-from-ai-studio),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `agent-platform-migrate-from-ai-studio`.
