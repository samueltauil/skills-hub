# dataverse-python-quickstart

Generate Python SDK setup + CRUD + bulk + paging snippets using official patterns.

This plugin packages the [`dataverse-python-quickstart`](skills/dataverse-python-quickstart/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/dataverse-python-quickstart) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/dataverse-python-quickstart/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install dataverse-python-quickstart@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddataverse-python-quickstart),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `dataverse-python-quickstart`.
