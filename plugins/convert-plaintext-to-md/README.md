# convert-plaintext-to-md

Convert a text-based document to markdown following instructions from prompt, or if a documented option is passed, follow the instructions for that option.

This plugin packages the [`convert-plaintext-to-md`](skills/convert-plaintext-to-md/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/convert-plaintext-to-md) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/convert-plaintext-to-md/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install convert-plaintext-to-md@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dconvert-plaintext-to-md),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `convert-plaintext-to-md`.
