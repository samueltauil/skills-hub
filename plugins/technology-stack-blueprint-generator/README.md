# technology-stack-blueprint-generator

Comprehensive technology stack blueprint generator that analyzes codebases to create detailed architectural documentation. Automatically detects technology stacks, programming languages, and implementation patterns across multiple platforms (.NET, Java, JavaScript, React, Python). Generates configurable blueprints with version information, licensing details, usage patterns, coding conventions, and visual diagrams. Provides implementation-ready templates and maintains architectural consistency for guided development.

This plugin packages the [`technology-stack-blueprint-generator`](skills/technology-stack-blueprint-generator/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/technology-stack-blueprint-generator) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/technology-stack-blueprint-generator/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install technology-stack-blueprint-generator@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dtechnology-stack-blueprint-generator),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `technology-stack-blueprint-generator`.
