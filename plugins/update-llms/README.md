# update-llms

Update the llms.txt file in the root folder to reflect changes in documentation or specifications following the llms.txt specification at https://llmstxt.org/

This plugin packages the [`update-llms`](skills/update-llms/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/update-llms) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/update-llms/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install update-llms@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dupdate-llms),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `update-llms`.
