# gtm-product-led-growth

Build self-serve acquisition and expansion motions. Use when deciding PLG vs sales-led, optimizing activation, driving freemium conversion, building growth equations, or recognizing when product complexity demands human touch. Includes the parallel test where sales-led won 10x on revenue.

This plugin packages the [`gtm-product-led-growth`](skills/gtm-product-led-growth/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-product-led-growth) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-product-led-growth/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-product-led-growth@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-product-led-growth),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-product-led-growth`.
