# create-implementation-plan

Create a new implementation plan file for new features, refactoring existing code or upgrading packages, design, architecture or infrastructure.

This plugin packages the [`create-implementation-plan`](skills/create-implementation-plan/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-implementation-plan) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-implementation-plan/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-implementation-plan@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-implementation-plan),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-implementation-plan`.
