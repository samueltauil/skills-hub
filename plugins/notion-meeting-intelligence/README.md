# notion-meeting-intelligence

Prepare meeting materials with Notion context and Codex research; use when gathering context, drafting agendas/pre-reads, and tailoring materials to attendees.

This plugin packages the [`notion-meeting-intelligence`](skills/notion-meeting-intelligence/SKILL.md) skill from
[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated/notion-meeting-intelligence) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/notion-meeting-intelligence/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install notion-meeting-intelligence@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dnotion-meeting-intelligence),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `notion-meeting-intelligence`.
