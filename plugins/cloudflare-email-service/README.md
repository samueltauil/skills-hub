# cloudflare-email-service

Implement or troubleshoot Cloudflare Email Sending and Email Routing integrations and their delivery configuration.

This plugin packages the [`cloudflare-email-service`](skills/cloudflare-email-service/SKILL.md) skill from
[cloudflare/skills](https://github.com/cloudflare/skills/tree/main/skills/cloudflare-email-service) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/cloudflare-email-service/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install cloudflare-email-service@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcloudflare-email-service),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `cloudflare-email-service`.
