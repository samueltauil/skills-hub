# google-cloud-solution-agentic-ai-bidirectional-streaming

Guides agents to interactively discover customer requirements for live, bidirectional multi-agent AI systems that process continuous streams of multimodal data for real-time technical guidance and safety monitoring. Generates a custom Google Cloud solution that uses opinionated best practices and architecture guidance. Use when users need agentic assistance to design and create a multi-product solution in the cloud for live bidirectional multimodal streaming workloads. Don't use for simple text-based chat applications or workloads without real-time streaming requirements.

This plugin packages the [`google-cloud-solution-agentic-ai-bidirectional-streaming`](skills/google-cloud-solution-agentic-ai-bidirectional-streaming/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/google-cloud-solution-agentic-ai-bidirectional-streaming) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-cloud-solution-agentic-ai-bidirectional-streaming/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

```sh

copilot plugin install google-cloud-solution-agentic-ai-bidirectional-streaming@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgoogle-cloud-solution-agentic-ai-bidirectional-streaming),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `google-cloud-solution-agentic-ai-bidirectional-streaming`.
