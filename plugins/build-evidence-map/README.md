# build-evidence-map

Build an auditable evidence map for a contested technical choice, research synthesis, proposal review, or consequential decision. Use when Copilot must preserve supporting, contradicting, qualifying, and missing evidence with exact source regions instead of collapsing disagreement into prose.

This plugin packages the [`build-evidence-map`](skills/build-evidence-map/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/build-evidence-map) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/build-evidence-map/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install build-evidence-map@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbuild-evidence-map),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `build-evidence-map`.
