# fabric-lakehouse

Use this skill to get context about Fabric Lakehouse and its features for software systems and AI-powered functions. It offers descriptions of Lakehouse data components, organization with schemas and shortcuts, access control, and code examples. This skill supports users in designing, building, and optimizing Lakehouse solutions using best practices.

This plugin packages the [`fabric-lakehouse`](skills/fabric-lakehouse/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/fabric-lakehouse) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/fabric-lakehouse/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install fabric-lakehouse@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfabric-lakehouse),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `fabric-lakehouse`.
