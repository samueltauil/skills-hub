# gtm-ai-gtm

Go-to-market strategy for AI products. Use when positioning AI products, handling "who is responsible when it breaks" objections, pricing variable-cost AI, choosing between copilot/agent/teammate framing, or selling autonomous tools into enterprises.

This plugin packages the [`gtm-ai-gtm`](skills/gtm-ai-gtm/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-ai-gtm) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-ai-gtm/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-ai-gtm@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-ai-gtm),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-ai-gtm`.
