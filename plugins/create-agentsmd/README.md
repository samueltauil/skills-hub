# create-agentsmd

Prompt for generating an AGENTS.md file for a repository

This plugin packages the [`create-agentsmd`](skills/create-agentsmd/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-agentsmd) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-agentsmd/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-agentsmd@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-agentsmd),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-agentsmd`.
