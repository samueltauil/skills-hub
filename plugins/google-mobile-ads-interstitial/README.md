# google-mobile-ads-interstitial

Provides instructions for implementing, integrating, or configuring Google Mobile Ads (GMA) SDK interstitial ads in Android, iOS, or Unity mobile applications. Use when the task involves setting up interstitial ads. Don't use for "rewarded interstitial" ads.

This plugin packages the [`google-mobile-ads-interstitial`](skills/google-mobile-ads-interstitial/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/ads/google-mobile-ads-interstitial) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-mobile-ads-interstitial/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install google-mobile-ads-interstitial@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgoogle-mobile-ads-interstitial),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `google-mobile-ads-interstitial`.
