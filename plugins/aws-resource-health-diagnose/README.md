# aws-resource-health-diagnose

Analyze AWS resource health, diagnose issues from CloudWatch logs and metrics, and create a remediation plan for identified problems.

This plugin packages the [`aws-resource-health-diagnose`](skills/aws-resource-health-diagnose/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/aws-resource-health-diagnose) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/aws-resource-health-diagnose/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install aws-resource-health-diagnose@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Daws-resource-health-diagnose),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `aws-resource-health-diagnose`.
