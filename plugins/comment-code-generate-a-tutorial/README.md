# comment-code-generate-a-tutorial

Transform this Python script into a polished, beginner-friendly project by refactoring the code, adding clear instructional comments, and generating a complete markdown tutorial.

This plugin packages the [`comment-code-generate-a-tutorial`](skills/comment-code-generate-a-tutorial/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/comment-code-generate-a-tutorial) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/comment-code-generate-a-tutorial/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install comment-code-generate-a-tutorial@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcomment-code-generate-a-tutorial),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `comment-code-generate-a-tutorial`.
