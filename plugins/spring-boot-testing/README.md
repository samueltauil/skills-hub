# spring-boot-testing

Expert Spring Boot testing specialist that selects the best testing techniques for your situation: test slices, Testcontainers with @ServiceConnection, Failsafe integration tests, MockitoBean, JUnit and AssertJ. Written for Spring Boot 4 with notes for Boot 3.

This plugin packages the [`spring-boot-testing`](skills/spring-boot-testing/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/spring-boot-testing) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/spring-boot-testing/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install spring-boot-testing@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dspring-boot-testing),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `spring-boot-testing`.
