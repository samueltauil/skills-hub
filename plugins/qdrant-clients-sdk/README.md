# qdrant-clients-sdk

Qdrant provides client SDKs for various programming languages, allowing easy integration with Qdrant deployments.

This plugin packages the [`qdrant-clients-sdk`](skills/qdrant-clients-sdk/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/qdrant-clients-sdk) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/qdrant-clients-sdk/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install qdrant-clients-sdk@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dqdrant-clients-sdk),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `qdrant-clients-sdk`.
