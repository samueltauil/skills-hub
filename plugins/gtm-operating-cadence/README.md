# gtm-operating-cadence

Design meeting rhythms, metric reporting, quarterly planning, and decision-making velocity for scaling companies. Use when decisions are slow, planning is broken, the company is growing but alignment is worse, or leadership meetings consume all time without producing decisions.

This plugin packages the [`gtm-operating-cadence`](skills/gtm-operating-cadence/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-operating-cadence) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-operating-cadence/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-operating-cadence@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-operating-cadence),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-operating-cadence`.
