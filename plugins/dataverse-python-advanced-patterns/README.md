# dataverse-python-advanced-patterns

Generate production code for Dataverse SDK using advanced patterns, error handling, and optimization techniques.

This plugin packages the [`dataverse-python-advanced-patterns`](skills/dataverse-python-advanced-patterns/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/dataverse-python-advanced-patterns) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/dataverse-python-advanced-patterns/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install dataverse-python-advanced-patterns@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddataverse-python-advanced-patterns),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `dataverse-python-advanced-patterns`.
