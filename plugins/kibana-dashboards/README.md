# kibana-dashboards

Create and manage Kibana Dashboards and Lens visualizations. Use when you need to define dashboards and visualizations declaratively, version control them, automate their deployment, or improve layout, sections, controls, or chart design.

This plugin packages the [`kibana-dashboards`](skills/kibana-dashboards/SKILL.md) skill from
[elastic/agent-skills](https://github.com/elastic/agent-skills/tree/main/skills/kibana/kibana-dashboards) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/kibana-dashboards/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install kibana-dashboards@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dkibana-dashboards),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `kibana-dashboards`.
