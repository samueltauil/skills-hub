# desk-open

Create and open a new desk in the workshop. Sets up the folder structure, initial journal, and desk identity so the next session that sits down finds the trail.

This plugin packages the [`desk-open`](skills/desk-open/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/desk-open) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/desk-open/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install desk-open@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddesk-open),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `desk-open`.
