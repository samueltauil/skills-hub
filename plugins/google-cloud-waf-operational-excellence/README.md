# google-cloud-waf-operational-excellence

Generates operational guidance for CI/CD deployment pipelines, observability, monitoring, logging, and incident management on Google Cloud based on the design principles and recommendations in the Operational Excellence pillar of the Google Cloud Well-Architected Framework (WAF). Use when the user asks about operations-related topics like capacity management, change management, incident and problem management, configuration management, deployment automation using infrastructure as code (IaC), or operational health checks for Google Cloud workloads.

This plugin packages the [`google-cloud-waf-operational-excellence`](skills/google-cloud-waf-operational-excellence/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/google-cloud-waf-operational-excellence) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-cloud-waf-operational-excellence/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install


search for `google-cloud-waf-operational-excellence`.
