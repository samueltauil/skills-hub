# refactor-method-complexity-reduce

Refactor given method `${input:methodName}` to reduce its cognitive complexity to `${input:complexityThreshold}` or below, by extracting helper methods.

This plugin packages the [`refactor-method-complexity-reduce`](skills/refactor-method-complexity-reduce/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/refactor-method-complexity-reduce) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/refactor-method-complexity-reduce/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install refactor-method-complexity-reduce@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Drefactor-method-complexity-reduce),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `refactor-method-complexity-reduce`.
