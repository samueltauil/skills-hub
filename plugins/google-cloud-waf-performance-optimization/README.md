# google-cloud-waf-performance-optimization

Generates performance-focused guidance for Google Cloud workloads based on the design principles and recommendations in the Performance Optimization pillar of the Google Cloud Well-Architected Framework (WAF). Use this skill to evaluate a workload, identify performance requirements, and provide actionable recommendations for resource allocation, modular design, and elasticity.

This plugin packages the [`google-cloud-waf-performance-optimization`](skills/google-cloud-waf-performance-optimization/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/google-cloud-waf-performance-optimization) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/google-cloud-waf-performance-optimization/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install google-cloud-waf-performance-optimization@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgoogle-cloud-waf-performance-optimization),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `google-cloud-waf-performance-optimization`.
