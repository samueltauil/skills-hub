# context-map

Generate a map of all files relevant to a task before making changes

This plugin packages the [`context-map`](skills/context-map/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/context-map) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/context-map/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install context-map@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcontext-map),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `context-map`.
