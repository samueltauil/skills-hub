# create-github-action-workflow-specification

Create a formal specification for an existing GitHub Actions CI/CD workflow, optimized for AI consumption and workflow maintenance.

This plugin packages the [`create-github-action-workflow-specification`](skills/create-github-action-workflow-specification/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/create-github-action-workflow-specification) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/create-github-action-workflow-specification/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install create-github-action-workflow-specification@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dcreate-github-action-workflow-specification),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `create-github-action-workflow-specification`.
