# add-educational-comments

Add educational comments to the file specified, or prompt asking for file to comment if one is not provided.

This plugin packages the [`add-educational-comments`](skills/add-educational-comments/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/add-educational-comments) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/add-educational-comments/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install add-educational-comments@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dadd-educational-comments),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `add-educational-comments`.
