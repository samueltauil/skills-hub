# repo-story-time

Generate a comprehensive repository summary and narrative story from commit history

This plugin packages the [`repo-story-time`](skills/repo-story-time/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/repo-story-time) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/repo-story-time/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install repo-story-time@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Drepo-story-time),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `repo-story-time`.
