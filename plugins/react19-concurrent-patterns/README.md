# react19-concurrent-patterns

Preserve React 18 concurrent patterns and adopt React 19 APIs (useTransition, useDeferredValue, Suspense, use(), useOptimistic, Actions) during migration.

This plugin packages the [`react19-concurrent-patterns`](skills/react19-concurrent-patterns/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/react19-concurrent-patterns) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/react19-concurrent-patterns/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install react19-concurrent-patterns@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dreact19-concurrent-patterns),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `react19-concurrent-patterns`.
