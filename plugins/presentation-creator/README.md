# presentation-creator

Create data-driven presentation slides using React, Vite, and Recharts with Sentry branding. Use when asked to "create a presentation", "build slides", "make a deck", "create a data presentation", "build a Sentry presentation". Scaffolds a complete slide-based app with charts, animations, and single-file HTML output.

This plugin packages the [`presentation-creator`](skills/presentation-creator/SKILL.md) skill from
[getsentry/skills](https://github.com/getsentry/skills/tree/main/skills/presentation-creator) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/presentation-creator/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install presentation-creator@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpresentation-creator),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `presentation-creator`.
