# firebase-auth-basics

Guide for setting up and using Firebase Authentication. Use this skill when the user's app requires user sign-in, user management, or secure data access using auth rules.

This plugin packages the [`firebase-auth-basics`](skills/firebase-auth-basics/SKILL.md) skill from
[firebase/agent-skills](https://github.com/firebase/agent-skills/tree/main/skills/firebase-auth-basics) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/firebase-auth-basics/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install firebase-auth-basics@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfirebase-auth-basics),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `firebase-auth-basics`.
