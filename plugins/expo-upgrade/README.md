# expo-upgrade

Guidelines for upgrading Expo SDK versions and fixing dependency issues

This plugin packages the [`expo-upgrade`](skills/expo-upgrade/SKILL.md) skill from
[expo/skills](https://github.com/expo/skills/tree/main/plugins/expo/skills/expo-upgrade) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/expo-upgrade/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install expo-upgrade@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dexpo-upgrade),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `expo-upgrade`.
