# web-artifacts-builder

Suite of tools for creating elaborate, multi-component claude.ai HTML artifacts using modern frontend web technologies (React, Tailwind CSS, shadcn/ui). Use for complex artifacts requiring state management, routing, or shadcn/ui components - not for simple single-file HTML/JSX artifacts.

This plugin packages the [`web-artifacts-builder`](skills/web-artifacts-builder/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/web-artifacts-builder) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/web-artifacts-builder/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install web-artifacts-builder@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dweb-artifacts-builder),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `web-artifacts-builder`.
