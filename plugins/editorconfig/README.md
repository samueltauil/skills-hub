# editorconfig

Generates a comprehensive and best-practice-oriented .editorconfig file based on project analysis and user preferences.

This plugin packages the [`editorconfig`](skills/editorconfig/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/editorconfig) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/editorconfig/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install editorconfig@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Deditorconfig),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `editorconfig`.
