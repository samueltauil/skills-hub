# vscode-ext-commands

Guidelines for contributing commands in VS Code extensions. Indicates naming convention, visibility, localization and other relevant attributes, following VS Code extension development guidelines, libraries and good practices

This plugin packages the [`vscode-ext-commands`](skills/vscode-ext-commands/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/vscode-ext-commands) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/vscode-ext-commands/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install vscode-ext-commands@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dvscode-ext-commands),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `vscode-ext-commands`.
