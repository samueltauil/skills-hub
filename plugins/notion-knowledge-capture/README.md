# notion-knowledge-capture

Capture conversations and decisions into structured Notion pages; use when turning chats/notes into wiki entries, how-tos, decisions, or FAQs with proper linking.

This plugin packages the [`notion-knowledge-capture`](skills/notion-knowledge-capture/SKILL.md) skill from
[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated/notion-knowledge-capture) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/notion-knowledge-capture/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install notion-knowledge-capture@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dnotion-knowledge-capture),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `notion-knowledge-capture`.
