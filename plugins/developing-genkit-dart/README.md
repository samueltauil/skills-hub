# developing-genkit-dart

Provides guidance on developing AI-powered applications using the Genkit Dart SDK. Use when the user asks to build AI agents in Dart, use Genkit flows, or integrate LLMs into Dart/Flutter applications. Don't use for Genkit in JavaScript/TypeScript, Go, or Python.

This plugin packages the [`developing-genkit-dart`](skills/developing-genkit-dart/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/developing-genkit-dart) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/developing-genkit-dart/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install developing-genkit-dart@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddeveloping-genkit-dart),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `developing-genkit-dart`.
