# power-apps-code-app-scaffold

Scaffold a complete Power Apps Code App project with PAC CLI setup, SDK integration, and connector configuration

This plugin packages the [`power-apps-code-app-scaffold`](skills/power-apps-code-app-scaffold/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/power-apps-code-app-scaffold) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/power-apps-code-app-scaffold/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install power-apps-code-app-scaffold@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpower-apps-code-app-scaffold),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `power-apps-code-app-scaffold`.
