# aspnet-core

Build, review, refactor, or architect ASP.NET Core web applications using current official guidance for .NET web development. Use when working on Blazor Web Apps, Razor Pages, MVC, Minimal APIs, controller-based Web APIs, SignalR, gRPC, middleware, dependency injection, configuration, authentication, authorization, testing, performance, deployment, or ASP.NET Core upgrades.

This plugin packages the [`aspnet-core`](skills/aspnet-core/SKILL.md) skill from
[openai/skills](https://github.com/openai/skills/tree/main/skills/.curated/aspnet-core) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/aspnet-core/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install aspnet-core@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Daspnet-core),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `aspnet-core`.
