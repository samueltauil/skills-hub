# frontend-design

Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. Helps with aesthetic direction, typography, and making choices that don't read as templated defaults.

This plugin packages the [`frontend-design`](skills/frontend-design/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/frontend-design/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install frontend-design@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dfrontend-design),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `frontend-design`.
