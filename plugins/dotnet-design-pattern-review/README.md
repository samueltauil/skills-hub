# dotnet-design-pattern-review

Review the C#/.NET code for design pattern implementation and suggest improvements.

This plugin packages the [`dotnet-design-pattern-review`](skills/dotnet-design-pattern-review/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/dotnet-design-pattern-review) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/dotnet-design-pattern-review/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install dotnet-design-pattern-review@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Ddotnet-design-pattern-review),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `dotnet-design-pattern-review`.
