# brand-guidelines

Applies Anthropic's official brand colors and typography to any sort of artifact that may benefit from having Anthropic's look-and-feel. Use it when brand colors or style guidelines, visual formatting, or company design standards apply.

This plugin packages the [`brand-guidelines`](skills/brand-guidelines/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/brand-guidelines) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/brand-guidelines/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install brand-guidelines@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbrand-guidelines),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `brand-guidelines`.
