# assuredworkloads-frameworks-author

Authors custom cloud controls and customized frameworks for Assured Workloads when built-in resources cannot satisfy core requirements. Use when creating or synthesizing custom data boundary resources. Don't use for browsing or mapping existing built-in frameworks (use assuredworkloads-frameworks-navigator instead).

This plugin packages the [`assuredworkloads-frameworks-author`](skills/assuredworkloads-frameworks-author/SKILL.md) skill from
[google/skills](https://github.com/google/skills/tree/main/skills/cloud/assuredworkloads-frameworks-author) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/assuredworkloads-frameworks-author/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install assuredworkloads-frameworks-author@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dassuredworkloads-frameworks-author),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `assuredworkloads-frameworks-author`.
