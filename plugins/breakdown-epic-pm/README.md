# breakdown-epic-pm

Prompt for creating an Epic Product Requirements Document (PRD) for a new epic. This PRD will be used as input for generating a technical architecture specification.

This plugin packages the [`breakdown-epic-pm`](skills/breakdown-epic-pm/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/breakdown-epic-pm) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/breakdown-epic-pm/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install breakdown-epic-pm@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dbreakdown-epic-pm),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `breakdown-epic-pm`.
