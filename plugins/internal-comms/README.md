# internal-comms

A set of resources to help me write all kinds of internal communications, using the formats that my company likes to use. Claude should use this skill whenever asked to write some sort of internal communications (status reports, leadership updates, 3P updates, company newsletters, FAQs, incident reports, project updates, etc.).

This plugin packages the [`internal-comms`](skills/internal-comms/SKILL.md) skill from
[anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/internal-comms) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/internal-comms/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install internal-comms@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dinternal-comms),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `internal-comms`.
