# premium-frontend-ui

A comprehensive guide for GitHub Copilot to craft immersive, high-performance web experiences with advanced motion, typography, and architectural craftsmanship.

This plugin packages the [`premium-frontend-ui`](skills/premium-frontend-ui/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/premium-frontend-ui) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/premium-frontend-ui/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install premium-frontend-ui@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dpremium-frontend-ui),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `premium-frontend-ui`.
