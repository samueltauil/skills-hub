# gem-devops-guidelines

Design or review infrastructure, deployment, CI/CD, Docker, Kubernetes, health checks, rollback, feature flags, production readiness, and mobile release workflows. Use for DevOps, platform, container, pipeline, or release tasks.

This plugin packages the [`gem-devops-guidelines`](skills/gem-devops-guidelines/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gem-devops-guidelines) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gem-devops-guidelines/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gem-devops-guidelines@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgem-devops-guidelines),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gem-devops-guidelines`.
