# developing-genkit-js

Provides guidance on developing AI-powered applications using Genkit in Node.js/TypeScript. Use when the user asks about Genkit, AI agents, flows, or tools in JavaScript/TypeScript, or when encountering Genkit errors, validation issues, type errors, or API problems. Don't use for Genkit in Python, Go, or Dart.

This plugin packages the [`developing-genkit-js`](skills/developing-genkit-js/SKILL.md) skill from

by [Skills Hub](https://skillshub.space/skills/developing-genkit-js/) and follows the
