# gtm-enterprise-account-planning

Strategic account planning and execution for enterprise deals. Use when planning complex sales cycles, managing multiple stakeholders, applying MEDDICC qualification, tracking deal health, or building mutual action plans. Includes the "stale MAP equals dead deal" pattern.

This plugin packages the [`gtm-enterprise-account-planning`](skills/gtm-enterprise-account-planning/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-enterprise-account-planning) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-enterprise-account-planning/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-enterprise-account-planning@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-enterprise-account-planning),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-enterprise-account-planning`.
