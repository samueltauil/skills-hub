# openapi-to-application-java-spring-boot

Generate a Spring Boot (Java) application from an OpenAPI 3 specification using the spec-first approach: openapi-generator (Maven or Gradle) produces API interfaces and DTOs, you implement controllers, services, persistence, security and tests. Use when asked to build, scaffold or implement a Spring Boot API from an OpenAPI/Swagger file.

This plugin packages the [`openapi-to-application-java-spring-boot`](skills/openapi-to-application-java-spring-boot/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/openapi-to-application-java-spring-boot) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/openapi-to-application-java-spring-boot/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.
