# gtm-developer-ecosystem

Build and scale developer-led adoption through ecosystem programs. Use when deciding open vs curated ecosystems, building developer programs, scaling platform adoption, or designing student program pipelines.

This plugin packages the [`gtm-developer-ecosystem`](skills/gtm-developer-ecosystem/SKILL.md) skill from
[github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills/gtm-developer-ecosystem) so it can be installed on its own. It is generated
by [Skills Hub](https://skillshub.space/skills/gtm-developer-ecosystem/) and follows the
[Agent Plugins](https://agent-plugins.org) specification.

## Install

GitHub Copilot CLI:

```sh
copilot plugin marketplace add samueltauil/skills-hub
copilot plugin install gtm-developer-ecosystem@skills-hub
```

VS Code (with `chat.plugins.enabled` turned on): [install with one click](https://vscode.dev/redirect?url=vscode%3A%2F%2Fchat-plugin%2Finstall%3Fsource%3Dsamueltauil%252Fskills-hub%26plugin%3Dgtm-developer-ecosystem),
or add the `samueltauil/skills-hub` marketplace from the Agent Customizations editor and
search for `gtm-developer-ecosystem`.
